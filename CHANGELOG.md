# Changelog

## 2.1.0 — Premium Edition
- Preserved the complete ContractLens AI application modules and existing interaction flows.
- Added premium.css with a refreshed typography system, indigo/navy visual palette, refined surfaces, responsive polish, and restrained animations.
- Added Windows and macOS/Linux launch scripts.
- Added a complete feature inventory and updated setup/privacy notes.
- Reset the distributed local vault so the package opens with an empty saved-contract history.


## 2.2.0 — Compare File Uploads
- Added separate drag-and-drop and browse upload areas for Contract A and Contract B in Compare.
- Added server-side text extraction for PDF, DOCX, TXT, Markdown, and RTF files, then prefilled the existing side-by-side comparison inputs.
- Added file type and 8 MB size validation, extracted-word status, and clear error feedback.
- Kept paste-in text, demo comparisons, and the existing comparison engine workflow available.

## 2.3.0 — Legal Translator Dark-Mode & Motion Polish
- Fixed low-contrast translator text by explicitly binding glossary buttons, detail content, in-contract context, and signing questions to theme-aware color tokens.
- Added a dark-mode palette treatment for the translator’s contract context and question panels, with readable text in both themes.
- Added staggered glossary-card entrance, a refined definition-panel reveal, smoother hover/focus states, and a reduced-motion fallback.
- Added automated theme-token contrast checks and route-level API smoke tests; the API test restores the local vault database after completion.
- Updated the app and health endpoint version to 2.3.0.
